# 1. OMRON connect を設定

スマートフォンの OMRON connect アプリで「血圧お知らせ定期便」を設定します。
お届け先には、このスプレッドシートを使う本人の Gmail を登録してください。

## 血圧お知らせ定期便について

過去 1 週間の血圧測定状況を、毎週日曜日に登録したメールアドレスへ届けるサービスです。
利用には、対応血圧計の機器登録とクラウドサービスへの登録が必要です。お届け先は最大 3 件まで登録できます。
詳しくは [OMRON 公式 FAQ「血圧お知らせ定期便」について](https://www.faq.healthcare.omron.co.jp/faq/show/18331?site_domain=oc) をご覧ください。

## 設定手順

1. 血圧計の測定データをアプリへ転送し、アプリ内に本人の記録が表示されることを確認します。
2. アプリの **コンテンツ** から **コンテンツライブラリー** を開き、**血圧お知らせ定期便** を選びます。
3. **定期便を利用する** をオンにします。
4. **あなたのニックネーム** を設定します。送信メールの測定者名に使われます。画面の注意に従い、フルネームは入力しないでください。
5. **お届け先を追加** から本人の Gmail を登録し、案内に従って承認を完了します。
   すでに登録済みの場合は、使う Gmail が登録されているか確認してください。
6. お届け先が **承認待ち** ではなく、配信される状態になったことを確認します。
7. 日曜日の配信後、本人の Gmail に定期便メールが届くことを確認します。

アプリの版や端末によって画面・表示名が異なる場合は、上記の公式 FAQ の「血圧お知らせ定期便の利用開始方法」を参照してください。

!!! warning "承認待ちでは配信されません"
    メールアドレスを追加するだけで終わらず、お届け先の承認まで完了してください。

## 初回メールを待っている場合

配信日は毎週日曜日です。設定直後にメールが届くとは限りません。
メールがまだ届いていなくても、次のテンプレートのコピー、初回 CSV の登録、週次トリガーの設定へ進めます。
受信後の確認は [5. 取込と週次トリガー](first-sync.md#first-email) に沿って行ってください。

受信確認の目安は、送信元 `noreply@bp-manager.com`、件名 `[OMRON connect]血圧お知らせ定期便` です。
届かない場合は、お届け先のアドレス・承認状態・利用の切替を確認し、Gmail の迷惑メールフォルダーも確認してください。

## 体重・体組成も記録する場合（任意）

対応する体重・体組成計をアプリに機器登録し、本人の測定データを転送できることを確認してください。
血圧お知らせ定期便の設定だけでは、体重・体組成は取り込まれません。
OMRON connect から CSV を書き出して本人の Gmail に送る操作が必要です。
詳しくは [体組成 CSV を送る](../usage/body-csv.md) をご覧ください。
