# 2. 権限の承認

取込用のプログラムが Gmail やスプレッドシートを使えるように、最初に一度だけ許可します。

## 手順

1. メニュー **健康データ → セットアップ ウィザード…** を選びます。
2. 「承認が必要です」と表示されたら **続行** を押し、ご自身の Google アカウントを選びます。
3. 「**Google はこのアプリを確認していません**」という警告が表示されます。
   内容に納得できる場合は、**詳細**（または「詳細を表示」）→ **（安全ではないページ）に移動** を押します。
4. 許可する内容の一覧が表示されます。確認して **許可**（または「続行」）を押します。
5. もう一度 **健康データ → セットアップ ウィザード…** を選ぶと、画面右側に手順の一覧が表示されます。
6. 一番上の **シートと設定** を実行します。必要なシート一式が作られます。
7. 続けて **体組成 CSV の送信元** を実行します。ご自身のメールアドレスが自動で設定されます。

## 警告が表示される理由

このツールは個人が配布しているもので、Google の審査（OAuth 検証）を受けていません。
そのため Google が「確認していないアプリ」として警告を表示します。

- プログラムは**外部への送信やメールの送信・削除を行いません**。データはご自身のアカウント内だけで処理されます。
- プログラムの全文は、メニュー **拡張機能 → Apps Script** から誰でも確認できます。
- 不安な場合は、承認せずに中止してください。

## 許可する内容

| 権限 | 使いみち |
|---|---|
| Gmail | 定期便メールと体組成 CSV メールを探して読む。取込済みの目印として**ラベルを作成・付与**する |
| スプレッドシート | 取り込んだデータを保存し、集計シートとグラフを更新する |
| トリガー | 毎週の自動取込を登録する |
| メールアドレス | 体組成 CSV メールの送信元として、ご自身のアドレスを設定する |

Gmail の権限は、ラベルを付けるため読み取り専用ではありません。ただし、メールの削除・送信・転送はしません。
承認画面の文言は Google が決めるため、上の表と表現が異なることがあります。

詳しくは [プライバシーポリシー](../privacy.md) をご覧ください。
