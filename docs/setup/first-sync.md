# 5. 取込と週次トリガー

Gmail に届いている定期便メールを取り込み、毎週の自動取込を登録します。
セットアップ ウィザードの残りの手順を、上から順に実行してください。

## 手順

1. **Gmail ラベル**: 定期便メールと体組成 CSV メールに、目印のラベル（`omron-bp`、`omron-body`）を付けます。
   Gmail でフィルタを作る必要はありません。
2. **試験取込（書込みなし）**: メールを読めるかだけを確認します。スプレッドシートには何も書き込みません。
   定期便の受信前や、初回 CSV の切替日以前のメールしかない場合は、対象が 0 件でも次へ進めます。
   エラーが表示された場合は、内容を確認して解消してください。
3. **週次トリガー**: 毎週月曜の 9 時台に自動で取り込むよう登録します。
4. **閲覧用データの更新**: 日別一覧・月間カレンダー・グラフのシートを作ります。

最後に、メニュー **健康データ → 今すぐ取込して表示を更新** を実行します。
届いている定期便メールが取り込まれ、表示が最新になります。

## 結果を確認する

メニュー **健康データ → 状態を確認** を選ぶと、`status` シートが開きます。

- 血圧・体組成の最終測定日と、最後に取込に成功した日時
- 週次トリガーが登録されているか
- 取り込めなかったメールがあるか（`⚠` が付いた行）

週次トリガーが登録され、初回 CSV の記録が `dashboard_daily`（日別）や `dashboard_calendar`（月間カレンダー）に表示されていれば、設定作業は完了です。
定期便がまだ届いていない場合は、受信後に次の確認を行ってください。

## 初回メールの受信後に確認する {#first-email}

1. OMRON connect に登録した本人の Gmail に、血圧お知らせ定期便が届いたことを確認します。
2. **健康データ → 今すぐ取込して表示を更新** を実行します。登録済みの週次トリガーによる月曜の取込を待ってもかまいません。
3. **健康データ → 状態を確認** で取込結果を確認し、日別一覧や月間カレンダーに新しい記録が反映されたことを確認します。

!!! note "メールが届いても追加されない場合"
    初回 CSV の最後の測定日（切替日）以前の記録は、重複を防ぐため定期便から追加されません。
    切替日より後の測定データを含む定期便で、追記できることを確認してください。

!!! tip "タイムゾーン"
    テンプレートは日本時間（Asia/Tokyo）に設定されています。日付が 1 日ずれて見える場合は、
    メニュー **健康データ → 詳細 → Sheet を日本時間に設定** を実行してください。

セットアップはこれで終わりです。次は [使い方](../usage/index.md) をご覧ください。
