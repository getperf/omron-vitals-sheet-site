# 1. テンプレートをコピー

## 手順

1. 次のリンクを開きます（Google アカウントにログインした状態で開いてください）。

    <!-- TODO(公開時): <TEMPLATE_ID> を検証済みテンプレートの ID に差し替える -->
    **[テンプレートをコピーする](https://docs.google.com/spreadsheets/d/<TEMPLATE_ID>/copy)**

2. 「コピーを作成しますか？」という画面が出たら、**コピーを作成** を押します。
3. ご自身の Google ドライブに「omron-vitals-sheet-vX.Y.Z のコピー」という名前のスプレッドシートができます。
   名前は自由に変えてかまいません。
4. スプレッドシートを開いて数秒待ち、上部のメニューに **健康データ** が表示されることを確認します。
   表示されない場合は、ページを再読み込みしてください。

## コピーされるもの・されないもの

- **コピーされる**: スプレッドシートと、そこに入っている取込用のプログラム。
- **コピーされない**: 開発者や他の利用者のデータ、自動取込の予約（トリガー）。
  データはこれから取り込み、自動取込はご自身で登録します。

!!! warning "共有しないでください"
    このスプレッドシートには、これから健康データがたまります。**ご本人だけ**が見られる状態のまま使い、
    「リンクを知っている全員」への共有は有効にしないでください。
