# 4. 初回 CSV の登録

定期便メールに含まれるのは直近 1 週間分だけです。それより前の記録は、OMRON Connect の CSV を一度だけ読み込んで登録します。

## 手順

1. OMRON Connect アプリで、**血圧**の記録を CSV でエクスポートします。 
2. メニュー **測定結果出力** を選択します。
   期間は開始月・終了月で指定します。残したい最初の月から、今月までを選んでください。
3. ご自身の Gmail に、件名 `[OMRON]測定結果` のメールが届きます。
4. 添付の `BloodPressure_YYYYMM-YYYYMM.csv` をパソコンにダウンロードします。
5. スプレッドシートに戻り、セットアップ ウィザードの **初期 CSV の読込** を実行します
   （メニュー **健康データ → 詳細 → CSV を読み込む（血圧・体組成を自動判別）** でも同じです）。
6. ダウンロードした CSV を選びます。プレビューで件数を確認し、登録します。
7. メニュー **健康データ → 詳細 → CSVの日付・AM/PMを再計算** を実行します。

登録すると、CSV の最後の測定日が「切替日」として記録されます。これより後の記録は、定期便メールから取り込まれます。

## 体組成（体重など）を読み込む場合

体組成データは、定期便メールの機能がありません。
OMRON Connect から手動で**体重**の記録のエクスポートが必要になります。
OMRON Connect で手順 2～3 の **体重**の記録のエクスポートすると、添付 `BodyComposition_YYYYMM-YYYYMM.csv` のメールが届きます。
届いたメールを、　**今すぐ取得して表示を更新**　で読み込みます。

または手順 4〜6 と同じ画面で読み込めます（血圧か体組成かは自動で判別します）。

体組成のメールは、次の取込で自動的に読み込まれます。そのためダウンロードせずに、メールのまま残しておいてもかまいません。

## うまくいかないとき

- **「見出しが違う」と表示されて止まる**: OMRON Connect からエクスポートした CSV をそのまま選んでください。
  Excel などで開いて保存し直すと、形式が変わって読み込めなくなることがあります。
- **同じ CSV を 2 回読み込んだ**: 同じ記録は追加されないので、そのままでかまいません。
- **この手順を後回しにしたい**: ウィザードの **スキップ** で飛ばせます。ただし CSV を登録するまで、切替日より前の記録は入りません。
