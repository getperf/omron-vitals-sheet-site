# コードを更新する

コピーしたスプレッドシートは、コピーした時点の版のまま動きます。テンプレートが新しくなっても、自動では更新されません。
新しい版を使うには、プログラムを貼り替えます。データはそのまま残ります。

## 版を確認する

メニュー **健康データ → 状態を確認** の `status` シートで、「コードの版」を見ます。

## 手順

1. 新しい版の `Code.gs` を開きます。
   <!-- TODO(公開時): アプリのリポジトリ / Release の URL に差し替える -->
   入手先: [omron-vitals-sheet のリリース](https://github.com/getperf/omron-vitals-sheet/releases)
2. スプレッドシートのメニュー **拡張機能 → Apps Script** を開きます。
3. 左の一覧の `Code.gs` を開き、中身をすべて選択して削除してから、新しい `Code.gs` の全文を貼り付けて保存します。
4. リリースノートに「`appsscript.json` の変更あり」と書かれている場合は、`appsscript.json` も同じように貼り替えます。
   （左の一覧に表示されていない場合は、**プロジェクトの設定 → 「appsscript.json」マニフェスト ファイルをエディタで表示する** にチェックを入れます。）
5. スプレッドシートを再読み込みし、メニュー **健康データ → セットアップ / 再点検** を実行します。
6. `status` シートで「コードの版」が新しくなったことを確認します。

!!! warning "新しい権限が必要な版"
    リリースノートに「新しい権限あり」と書かれている版では、手順 5 で再び承認画面が表示されます。
    [権限の承認](../setup/authorize.md) と同じように確認してから許可してください。

テンプレートから新しくコピーし直す方法もありますが、その場合はデータを最初から取り込み直すことになります。
