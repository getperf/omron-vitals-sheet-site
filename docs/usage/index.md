# 使い方

セットアップが終われば、血圧は**何もしなくても毎週更新されます**。

## 毎週の流れ

1. OMRON Connect から、毎週「血圧お知らせ定期便」メールが Gmail に届きます。
2. 毎週月曜の 9 時台に、スプレッドシートが自動で次の順に取り込みます。
    1. 血圧（定期便メール）
    2. 体組成（ご自身で送った CSV メール）
    3. 日別一覧・カレンダー・グラフの更新
3. 途中の段階で失敗した場合も、残りの段階は実行されます。失敗したことは Google からメールで通知されます。

すぐに最新にしたいときは、メニュー **健康データ → 今すぐ取込して表示を更新** を実行してください。

## ときどき確認すること

メニュー **健康データ → 状態を確認** で `status` シートを開き、`⚠` の付いた行がないかを見てください。

| 表示 | 対処 |
|---|---|
| 週次同期が 9 日以上実行されていません | 週次トリガーが外れている可能性があります。**詳細 → 週次トリガーを登録** を実行する |
| 失敗記録（直近 7 日）が 1 以上 | `failed_imports` シートに理由が記録されています。OMRON Connect のメール形式が変わった可能性があります |
| 構成の版が違う | コードを更新したあとです。**セットアップ / 再点検** を実行する |

## 定期便に含まれる内容

定期便メールに含まれるのは、**日付・朝/晩の血圧・測定回数**だけです。
測定時刻・脈拍・機種は含まれないため、スプレッドシートにも入りません。
正確な記録は OMRON Connect アプリが正本です。
