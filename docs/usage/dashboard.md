# 閲覧用シートとグラフ

取込のたびに、次のシートが自動で作り直されます。**手で書き込んだ内容は次の更新で消える**ので、
メモなどは別のシートに書いてください。

| シート | 内容 |
|---|---|
| `dashboard_daily` | 日別の一覧（朝・晩の血圧、体重） |
| `dashboard_calendar` | 月間カレンダー形式の一覧 |
| `dashboard_weight_points` | 体重の全測定 |
| `dashboard_monthly` | 月ごとの平均 |
| `dashboard_charts` | 月次グラフ（収縮期・拡張期・体重 × 全期間・直近 12 か月の計 6 つ） |

## グラフについて

- 血圧のグラフには基準線（収縮期 135 / 拡張期 85 mmHg）を引いています。
  値は `settings` シートの `BP_REF_SYSTOLIC` / `BP_REF_DIASTOLIC` で変えられます。
- 測定のない月は前後を線でつなぎます。直近 12 か月のグラフには、月平均の値を表示します。
- 体重のグラフは、最初に測定した月から描きます。
- グラフも毎回作り直されるため、手で加えたグラフは残りません。独自のグラフは別のシートに作ってください。

## 触らないでほしいシート

| シート | 役割 |
|---|---|
| `master_measurements`、`master_body_composition` | 取り込んだ記録の本体 |
| `raw_csv_initial` | 初回 CSV の原本 |
| `settings` | 設定値。必要なときだけ変える |
| `import_log`、`failed_imports` | 取込の記録。不具合の確認に使うため消さない |
| `dashboard_chart_feed` | グラフ用の作業シート |

!!! note
    このスプレッドシートの値は、OMRON Connect の記録を転記・集計したものです。
    取込の不具合や形式変更で、元の記録と異なることがあります。大事な判断は OMRON Connect アプリの記録で確認してください。
